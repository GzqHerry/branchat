# branchat

branchat 是一个面向 Codex 的本地 Web 对话工作台：用树状分支浏览完整提问历史，在任意节点继续对话，并通过 SSH 让 Codex 在远程机器上运行和编辑代码。

它作为独立网页服务运行，不修改 Codex 桌面客户端，也不接管原生输入框。

## 功能

- 对话和提问树：从任意已完成节点创建互不影响的分支。
- 实时流式输出：思考计时、处理记录、文件编辑和命令执行状态。
- 可折叠思考记录、自动跟随滚动、LaTeX（KaTeX）和代码高亮。
- 排队提问、停止回答、失败重试、删除及回收站恢复。
- 本地 Codex 与 SSH 远程 Codex 双模式。
- 模型与推理强度选择、深色/浅色主题和可配置配色。

## 启动

在 Windows 资源管理器中双击 `Start.cmd`。已有后台服务时只打开新页面，首次运行才启动服务。连续双击或同时打开多个窗口会复用同一个后台，不会断开已有 SSH 或中断提问。默认地址为 `http://127.0.0.1:47831`；端口被其他程序占用时会自动递增。需要更新后端或主动重启时双击 `Restart.cmd`；重启会断开全部 SSH，已保存的分支和草稿保留。双击 `Stop.cmd` 停止服务。

若由 Codex 沙箱启动的服务读取正常但联网报 `EACCES`，请使用上述脚本在正常 Windows 账户中启动。脚本只对本次 PowerShell 进程指定执行策略，不更改系统执行策略。

## 使用

1. 选择一个本地对话，左侧会列出全部提问。支持搜索、展开和收起。
2. 点击历史提问，可查看截至此处的问答。发送新问题会在此处创建独立分支，也可先点击分叉图标。
3. 点击分支名称或该分支最后一条提问，可继续该分支。各分支草稿独立保存。
4. 点击标题右侧的更多操作图标重命名、收藏、导出或删除分支。回答中可点击停止图标。
5. 每轮进度说明和执行记录集中在可折叠的“处理记录”中：处理时展开，正式答案开始输出后自动收起，答案单独显示。点击标题可重新展开；手动展开或收起的状态在同步时保留。内部执行记录可查看命令、输出、文件路径及增删差异。
6. 新输出默认自动滚动到底部。向上翻阅时暂停跟随，有新内容时显示提示，点击向下箭头恢复跟随。
7. 点击对话选择器打开历史面板，按标题或目录搜索；历史按更新时间分组，归档对话可单独显示。
8. 点击侧栏右上角的新建图标，或历史面板底部的“新建对话”，从空白上下文开始。第一条消息发送前作为本地草稿保存；发送后创建独立的网页主对话，可继续提问、重命名和分叉，服务重启后保留。
9. Enter 发送，Shift+Enter 换行；中文输入法确认候选词时不触发发送。

回答进行中仍可输入下一个问题。在当前分支末尾按 Enter 或点击“加入提问队列”，问题会按顺序等待上一轮完成，再自动发送。输入框上方显示队列，可移除尚未发送的问题，或暂停、继续队列；每个分支最多排队 20 条。

队列保存在当前浏览器，刷新后恢复，切换分支仍继续工作；关闭所有提问树网页后暂停调度，重新打开后继续。多标签页共享队列并使用浏览器锁避免重复发送。停止回答或上一轮失败会暂停后续问题。连接中断且发送结果不明时先核对历史，不盲目重发；可点击“检查发送状态”，未确认的内容保留在队列中。
10. 顶栏设置图标提供白天、黑夜、跟随系统，以及松绿、湖蓝、玫红、琥珀、石墨五种强调色。设置保存在当前浏览器。
11. 选中分支后，从更多操作菜单删除。确认框会列出该分支及其子分支；删除后回到父对话的分叉位置。顶部可撤销最近一次删除，侧栏底部回收站可恢复更早删除的分支。正在回答的分支需先停止。

## 阅读与探索

提问树中的问题行在鼠标悬停或键盘聚焦时显示删除图标，触屏设备直接显示。点击后先预览删除范围；确认会移除该轮及之后的问答，以及从这些轮次派生的子分支。更早分叉且不包含这些轮次的分支保留。相关回答需先停止，结构变化时需重新确认。

删除提问会通过 `beforeTurnId` 创建真正截断的新上下文，用它承接原树位置的后续提问。旧运行上下文保存在回收站，搜索及普通发送不再使用它；上下文版本检查阻止旧页面或旧队列意外发送，队列会暂停供确认。对 Codex IDE 导入的原对话，只修改网页中的独立副本，IDE 原记录保持不变。

回收站中的提问记录恢复为一个新的独立对话，带回删除时的完整路径及关联子分支，不覆盖删除后产生的新问答。更早单独删除的子分支保持已删除状态。完整备份会把尚未恢复的提问回收记录作为独立的“回收站快照”保存。

侧栏底部使用带文字的“全文搜索 / 收藏备注 / 回收站 / 定位当前”入口，手机布局同样可用。回收站只负责查看和恢复已删除的分支；删除操作位于分支菜单底部，单独以警示色显示。

分支菜单支持方向键、Home / End 和 Escape，关闭后可返回触发按钮。输入框随多行文字自动增高，复制成功有可见提示。没有内容变化的后台同步会保留消息 DOM，避免打断选文和阅读；定位按钮会清除遮挡目标的搜索筛选。

- 标题下的路径可返回父分支和分叉提问。侧栏底部定位按钮展开并定位当前节点；分支显示运行、完成、失败与未读状态。
- 每个问题支持收藏和备注，侧栏星标入口集中查看收藏、备注、归档；对话归档保存在面板自己的目录中。
- 回答目录按 Markdown 标题生成。共同历史可以折叠，设置中可调整字号、行距和正文宽度；切换节点保存各自阅读位置。
- 消息下方可复制纯文本、Markdown、分叉或引用。代码块显示语言、复制和折叠按钮，公式悬停可复制 LaTeX。选择回答文本可引用或引用后分叉。
- 重新生成在目标提问之前创建新分支，再提交相同问题，原答案保留。失败或停止的问题也有重试入口。
- 对照按钮选择另一个分支，桌面并排显示，窄屏单独展开对照面板。默认隐藏相同轮次；引用按钮会把来源和正文明确插入当前输入框，需要主动发送。
- 侧栏全文搜索扫描本地问答索引，支持问题和答案定位，最多显示 200 条结果；不搜索内部推理或工具日志。
- 分支收到首个问题后，以该问题的简短文本自动命名；原编号保留为辅助信息，手工命名不会被覆盖。
- 模型旁显示服务实际提供的最近请求 token 用量和上下文窗口；服务没有提供时明确显示未知。
- 更多操作中的轻量分支允许手动编写或让模型生成摘要，确认和编辑后携带摘要及新问题创建独立上下文。生成摘要属于一次模型请求，可停止；不会把完整原始历史或工具运行环境带入。

## 备份与恢复

设置中的备份保存全部主对话、分支关系、公开消息、回收站、收藏备注，以及当前浏览器的草稿、阅读位置和外观配置。不包含认证文件或内部推理。单个备份上限 64 MB。

导入前显示对话和分支数量；导入为新的历史副本，重新映射节点 ID 和书签、草稿位置，不覆盖现有对话。当前浏览器外观保持原设置。导入记录可以阅读、搜索、对照、导出，通过轻量分支确认上下文后继续提问。JSON 备份是可迁移的问答档案，不是 Codex 运行环境、项目文件或工具会话的恢复镜像。

本轮升级新增后端接口，需要双击 `Restart.cmd` 重启一次，再刷新网页。重启前请等待正在进行的回答结束。

升级到包含新建对话和主题设置的版本后，需要双击一次 `Restart.cmd` 加载新版后端，单纯刷新页面不够。原有对话和分支仍保留。

新增分支删除接口的版本同样需要重启一次。删除采用持久化隐藏标记，保留历史与输入草稿供撤销，不清理磁盘上的会话文件；撤销只恢复同次删除的分支，不恢复更早单独删除的子分支。删除范围发生变化时，需要重新确认。

原对话为只读，正在进行的原始轮次不能作为分叉点。新分支通过 Codex App Server 的 `thread/fork` 和 `lastTurnId` 继承共同历史，后续上下文分别保存。

## 本机编辑

文件编辑默认启用，没有模式切换或工作目录配置步骤。直接说明要创建或修改什么，必要时在问题里说明文件位置。新对话自动在 `outputs/projects/` 中获得独立项目目录；已有任务沿用保存的文件位置，网页分支继承原任务的位置。IDE 原对话仍从历史节点创建独立网页分支继续。

执行与审批使用本机 Codex App Server 的 `workspace-write` 和 `on-request` 策略。任务目录及其子目录默认可写；目录外写入、工具联网等操作由 Codex 判断是否需要申请，不要求用户更换工作目录。访问请求自动显示在对话下方、输入框上方，包含申请原因、路径、命令与已提供的文件差异。

按请求类型提供“拒绝”“允许一次 / 允许本轮”“本次会话允许”等 Codex 原生选项；若运行时仅允许特定选项，网页只提供这些选项。命令或网络规则只能使用运行时实际提出的规则，页面不能扩大权限。选择会话授权后，后续提问不会重复重置权限；服务重启或运行时会话结束后，临时授权可能需要重新申请。

当前分支的请求直接出现，其他分支通过顶栏计数提示，可展开处理或跳转。刷新后恢复待处理请求；同步和新请求不会清空正在填写的补充回答。没有请求时不显示权限面板。内部摘要生成不执行工具；轻量分支则与其他任务一样默认可编辑。导入备份不导入权限授权。

分支隔离的是对话上下文，同一目录里的文件由各分支共用。删除问答不会撤销已经执行的文件修改。此模式不提供管理员权限或桌面插件宿主。

## SSH 远程连接

点击顶栏“本地连接”可管理 SSH 主机。保存主机名称、IP / 域名、SSH 用户名和端口后，选择“连接”。密码只用于本次连接，不写入磁盘；也可填写本机私钥路径，或留空使用 SSH Agent。首次连接须核对并确认 SHA256 主机指纹，后续连接校验已保存的指纹；指纹变化时会再次提示。

网页和全部网页后端运行在本机，通过 SSH 的标准输入输出通道直接启动并连接远程 Codex App Server。采用 [官方 App Server 协议](https://learn.chatgpt.com/docs/app-server)，远程无需为网页安装 Node.js、Python、npm 包或 HTTP 服务，只需有可运行且已登录的 Codex。自动检查 PATH、VS Code 远程扩展附带的原生可执行文件及常见 Codex 安装位置；没有找到时会说明如何准备远程 Codex。

连接成功后顶栏显示“SSH · 主机名”。新建对话、模型运行、命令执行、文件编辑及访问批准发生在远程机器；公开进度、答案和审批通过 SSH 实时传递。远程项目自动创建于 `~/CodexProjects/` 下的独立目录，已有任务沿用远程位置，不需要逐个配置工作目录。不会把本机认证文件或项目上传到远程，也不会把远程路径当成本机路径执行。

分支关系、回收站和备注保存在本机 `work/tree-data/ssh-hosts/<连接ID>/`，模型的原生对话历史由远程 Codex 保存。远程草稿和提问队列按连接分开；浏览器地址中的 `host` 标识当前连接，多个标签页可以使用不同主机。点击连接入口可切回本机。删除网页分支采用本机隐藏记录，后续读取远程目录时不会让已删分支重新出现。

同一主机的多个窗口共享一条 SSH 连接和远程 Codex 实例，可同时在不同对话中提问；同一个对话内仍按轮次排队。打开、刷新或关闭一个网页不会断开其他窗口。连接菜单中的“断开此主机”会明确提醒它影响该主机的所有窗口。

断开 SSH 会关闭该连接启动的 Codex 通道，正在执行的任务可能中断，已保存的历史可以重新连接后查看。不会保存密码并自动重连。连接界面分别显示 SSH 登录、寻找 Codex、启动 Codex 和就绪状态；远程连接失败时不会退回本机执行。

连接资料与信任指纹保存在 `work/tree-data/ssh-connections.json`，不含密码或私钥内容。原有主机配置、主机 ID 及浏览器草稿继续使用。旧版曾部署的远程网页服务和目录不会被自动删除；直连模式使用远程 Codex 当前账户的原生历史，旧版独立运行目录中的数据需要单独迁移。

升级后需双击一次 `Restart.cmd` 重启本机后端。`test/launcher.test.mjs` 验证并发双击只启动一个后台、重复打开保持输出流及显式重启。`test/ssh-direct.test.mjs` 使用本地 SSH 测试服务器验证真实 SSH 标准流通信与本机后端，包括双窗口并发提问与输出、单窗口关闭、新建、分叉、隐藏删除、审批和断线；`test/ssh-ui-check.mjs` 验证界面和主机隔离，不调用模型。

## 数据与依赖

- 适配本机 Codex 0.153.4。依赖 Node.js、Codex 和 Python 运行时；SSH 使用 `ssh2`（依赖已在当前目录安装）。在新的本机安装目录使用 `npm ci --omit=dev --ignore-scripts` 安装运行依赖。SSH 远程端只运行 Codex。
- 原始会话数据库以只读方式打开。所选会话的日志和历史索引复制到独立运行目录，原会话不被改写。
- 运行数据位于本项目的 `work/tree-data/`，与 `outputs/` 同级。`branches.json` 保存分支关系和网页主对话目录；`codex-home/` 保存对话历史及本地认证副本。不要分享该目录。
- 面板复用本机 `auth.json` 及模型提供商配置，模型请求发往用户已配置的服务。认证内容不写入前端或 URL。
- 草稿位于当前浏览器的本地存储。清除浏览器站点数据会删除草稿，但不会删除分支。
- 第三方 Lucide 图标按 ISC 许可分发，见 `LUCIDE-LICENSE`。
- Markdown 解析使用 Marked，见 `MARKED-LICENSE.md`。页面以 DOM 节点渲染解析结果，不执行历史消息中的 HTML。
- LaTeX 使用本地打包的 KaTeX 0.18.7，见 `KATEX-LICENSE.txt`，输出原生 MathML。支持 `\(...\)`、`\[...\]`、`$...$`、`$$...$$`，包括表格、列表与流式回答中的公式；代码块保持原样。长公式在自身区域横向滚动，语法错误保留原文。

本机路径可通过 `TREE_CODEX_EXE`、`TREE_PYTHON`、`TREE_SOURCE_HOME`、`TREE_DATA_DIR` 和 `PORT` 环境变量覆盖。若移动代码目录，需同时指定原来的 `TREE_DATA_DIR` 以继续使用已有分支。SQLite 历史导入适配当前版本的内部存储格式，Codex 升级后应重新验证。

## 验证

`npm test` 对运行中的本地服务检查历史节点、分支独立性、原对话只读和跨站请求限制，不调用模型。`TREE_TEST_URL` 可指定服务地址。

已验证真实历史读取、官方分叉接口和分支隔离。正常 Windows 账户启动后，用户在“分支 3”的实际测试已成功收到模型回答（该次耗时约 117 秒）。页面通过实时事件及每 2 秒的后台状态核对同步回答，计时每秒刷新；重新连接或回到页面时也会补全历史。

网页分支直接订阅自己的 App Server 事件：等待模型、思考、处理、输出和完成。思考计时依据页面接收到的 reasoning 开始/结束事件，是客户端观测时长；没有这些事件时仅显示本轮等待时长。它不显示模型的内部推理文本。

工作进度和执行记录来自公开的 commentary、工具及文件修改事件；执行中显示动效，并遵循系统的减少动画设置。文件差异与命令输出只有在服务提供相应内容后才会显示，缺失的内容不会补写。`test/activity-events-server.mjs` 是不调用模型的可控事件测试服务；`test/activity-ui-check.mjs` 可配合 Playwright 验证进度、滚动和手机布局。

`test/appearance-ui-check.mjs` 使用模拟 API 检查历史列表、新建会话流程、键盘输入、主题保存和响应式布局，不发送模型请求。运行时通过 `TREE_PLAYWRIGHT` 指定已有 Playwright 模块，通过 `TREE_BROWSER_EXE` 指定浏览器，通过 `TREE_TEST_URL` 指定运行着新版静态资源的服务。

`test/math-ui-check.mjs` 使用独立事件测试服务验证 PPO 公式、四种分隔符、代码与金额、异常公式、严格 CSP、窄屏横向滚动和流式排版，不调用模型。数学排版源码为 `src/markdown.js`，通过 `npm run build:markdown` 打包为现有的 `public/markdown.js`；正常运行不需要 npm 安装或外部 CDN。构建依赖可安装在单独目录，并用 `TREE_MATH_DEPS` 指向该目录。

`test/workbench-ui-check.mjs` 验证收藏备注、全文定位、阅读设置与位置、代码折叠、共同历史、对照引用、摘要预览、备选生成、回收站、下载及桌面/手机布局。`test/library.test.mjs` 检查备份 ID 重映射、关系校验、循环拒绝、字段约束和公开内容导出。

2026-09-09 已在新版正常启动的服务上完成完整真实模型验证：新对话无需配置模式或目录，直接通过文件编辑工具创建并读取文件；跨目录操作真实触发批准卡片，在网页点击批准后完成写入。目录级权限请求刷新后保留，批准前目标文件不存在；通过网页选择“本次会话允许”后，模型创建并读回 `first.txt`，下一轮在同一项目外目录创建并读回 `second.txt`，未再次申请权限，也未改变任务目录。

本机 Codex 0.153.4 的目录级申请工具由 `features.request_permissions_tool` 控制，本面板已启用并持久化此配置。升级前已经加载的运行时会话仍可能沿用原工具列表，可通过新建分支加载新配置；正常服务重启也会加载。审批由 Codex 原生运行时执行，单次命令批准与目录级会话授权的选项以实际请求为准。

IDE 原对话是另一个进程的会话，网页读取它已保存的历史，每 2 秒核对一次；实际延迟还取决于 IDE 写入历史的时机和读取耗时。这不是同一条实时事件流，无法保证两端同时出现每个字。查看最新提问时会自动跟随新轮次；主动查看历史节点时保持该位置。
